# Agent instructions for Qwakk

Read and follow [CLAUDE.md](./CLAUDE.md) before making changes. It is the source of truth for Qwakk product, brand, safety, engineering and Git rules.

Additional requirements:

- Keep work focused on the requested change and preserve unrelated work in the repository.
- Use concise, user-facing Turkish when communicating with the project owner.
- Do not deploy through Sites. This project is deployed by the owner through CapRover.
- Do not run `npm run dev` or other persistent development servers unless explicitly requested.
- Before any requested commit, verify the staged diff and use a Conventional Commit message as required by `CLAUDE.md`.
